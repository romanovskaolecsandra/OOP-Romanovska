Валідація у властивостях: підходи і приклади
Валідація –  це просто перевірка даних на правильність. Вона потрібна для того, щоб програма не працювала з помилковими значеннями. Наприклад, щоб користувач не міг випадково ввести від'ємний вік або залишити пустим поле з іменем.
1. Які є способи валідації?
a) Перевірка через блок set. Це найпростіший і найпопулярніший спосіб. Ми розгортаємо властивість і всередині set пишемо звичайну умову if.
b) Використання атрибутів. Це коли над властивістю просто пишуть готові правила в дужках, наприклад [Required], щоб поле обов'язково було заповнене.
d) Окремі функції. Якщо перевірка дуже велика і складна, її логіку виносять в окремий метод, а в set просто його викликають.

      2. Приклад з помилками (ArgumentException)
Якщо дані не проходять перевірку, програма зазвичай видає помилку (виняток). Це зупиняє код і не дає зберегти неправильні дані.
Приклад: 
public class Person
{
private string name;
private int age;
public string Name { get { return name; } set { if (value == "") { throw new ArgumentException("Ім'я не може бути пустим!"); } name = value; } }
public int Age { get { return age; } set { if (value < 0) { throw new ArgumentException("Вік не може бути меншим за 0!"); } age = value; } }
}

     3. Чи треба перевіряти абсолютно всі властивості?
Ні, для всіх властивостей це робити не варто.
Це роздуває код. Якщо поле може приймати будь-який текст (наприклад, якийсь коментар чи опис), то писати для нього перевірки просто немає сенсу. Тут краще використати звичайну коротку автовластивість. Властивості мають бути швидкими та простими. Якщо перевірка вимагає підключення до бази даних або складних обчислень, її треба робити в інших частинах програми, а не всередині властивості.
