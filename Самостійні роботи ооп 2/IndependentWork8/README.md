# Самостійна робота №8: Узагальнений кеш `Cache<TKey, TValue>` із тестами

## Опис проєкту
Консольний застосунок на C# (.NET), що реалізує узагальнений клас кешу `Cache<TKey, TValue>` з обмеженою ємністю та політикою видалення найстаріших елементів **FIFO (First In, First Out)**, а також набір юніт-тестів для перевірки його роботи.

## Структура рішення
* **`IndependentWork7`** — основний проєкт із реалізацією класу `Cache<TKey, TValue>` та демонстрацією роботи у `Program.cs`.
* **`IndependentWork7.Tests`** — проєкт юніт-тестів на базі **xUnit**, що покриває методи `Add`, `Get`, `ContainsKey`, властивість `Count`, витіснення при переповненні та виняток `KeyNotFoundException`.

## Запуск проєкту та тестів

Запуск демонстраційної програми:
```bash
dotnet run --project IndependentWork7
```

Запуск юніт-тестів:
```bash
dotnet test
```
