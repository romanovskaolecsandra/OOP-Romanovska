# Самостійна робота №12: LINQ pipelines — ETL та аналітика

## Опис проєкту
Консольний застосунок на C#, що моделює аналітичну обробку даних про продажі (`Sale`, `Product`, `Customer`) за допомогою складних багатоетапних LINQ-пайплайнів та вимірює швидкість їх виконання через `Stopwatch`. Детальний аналіз наведено у файлі [REPORT.md](REPORT.md).

## Запуск
```bash
dotnet run
```
