# Самостійна робота №13: PLINQ — дослідження продуктивності та безпеки

## Опис проєкту
Консольний застосунок на C#, що порівнює швидкодію звичайного LINQ та паралельного PLINQ (`AsParallel()`) на колекціях обсягом 1M, 5M та 10M елементів, а також демонструє проблему стану гонитви (*race condition*) і способи її вирішення (`lock`, `Interlocked`, `ConcurrentBag<T>`). Детальний аналіз результатів наведено у файлі [REPORT.md](REPORT.md).

## Запуск
```bash
dotnet run
```
