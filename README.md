# Лабораторна робота №2
**Виконала:** Романовська Олександра (Варіант 2 — Клас Car)

## Що я зробила:
- Оновила клас `Car` у файлі `Program.cs`. Додала приватні поля та валідацію року випуску (якщо рік з майбутнього, ставиться дефолтний 2000-й).
- Створила два конструктори й зв'язала їх через `this()`, щоб уникнути дублювання коду.
- Додала деструктор `~Car()` для відстеження життєвого циклу об'єкта.
- В кінці програми занулила змінні та викликала збирач сміття `GC.Collect()`.

## Відповіді на запитання:
1. **Перевантаження конструкторів** — це створення кількох конструкторів з різними параметрами. Це дає гнучкість при створенні об'єктів.
2. **Ключове слово `this()`** дозволяє викликати один конструктор з іншого, щоб вся логіка ініціалізації була в одному місці.
3. **Деструктор викликає** автоматично збирач сміття (Garbage Collector), коли на об'єкт більше немає посилань.
4. **Вручну `GC.Collect()` не викликають**, бо система сама оптимізує очищення пам'яті, а ручний виклик може уповільнити програму.
