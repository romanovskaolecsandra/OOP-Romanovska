# Лабораторна робота №3: Життєвий цикл об'єктів та патерн Dispose

Виконала: Студентка
Варіант: №2 (Клас DatabaseConnection)

## Мета роботи
Вивчити принципи керування пам'яттю в C# та навчитися правильно звільняти некеровані ресурси за допомогою інтерфейсу IDisposable та патерну Dispose.

## Результати виконання
Програма успішно запустилася через консоль та продемонструвала три варіанти очищення пам'яті:
1. Автоматично через конструкцію using — об'єкт самостійно викликав Dispose після виходу з блоку коду.
2. Вручну через прямий виклик методу db2.Dispose() у потрібний момент часу.
3. Автоматично через збирач сміття (GC.Collect) — коли об'єкт залишили без ручного очищення, система сама видалила його за допомогою деструктора.

## Висновок
На цій лабораторній роботі я розібралася з життєвим циклом об'єктів у C#. Я навчилася створювати класи з інтерфейсом IDisposable та реалізувала патерн Dispose. Тепер я знаю, що підключення до баз даних та інші зовнішні ресурси потрібно обов'язково закривати за допомогою using або вручну, щоб програма працювала стабільно і не займала зайву пам'ять.
