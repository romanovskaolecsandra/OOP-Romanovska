# Самостійна робота №1

## Відповіді на контрольні запитання

1. **Які мінімальні елементи повинен містити клас у цьому завданні?**
Він має мати хоча б 2 приватних поля для зберігання якихось даних, одну публічну властивість з get і set, щоб до цих даних достукатися, один конструктор, щоб з самого початку закинути в об'єкт значення, і хоча б один метод, який робить якісь підрахунки.

2. **Чому поля доцільно робити приватними, а доступ до них надавати через властивості?**
Це робиться для безпеки, щоб ніхто випадково «ззовні» не зламав логіку класу і не записав туди якийсь бред (наприклад, мінусову ширину для прямокутника). Через властивості ми можемо контролювати, що саме записується в поля.

3. **Для чого в класі потрібен конструктор і як він пов'язаний зі станом об'єкта?**
Конструктор автоматично спрацьовує, коли ми створюємо новий об'єкт через оператор `new`. Він потрібен, щоб одразу заповнити приватні поля початковими даними і об'єкт відразу був готовий до нормальної роботи.

4. **Як у Main показати, що методи класу працюють коректно?**
Треба просто створити екземпляр класу (наш об'єкт), викликати його метод з якимись тестовими числами і вивести результат у консоль через `Console.WriteLine`, щоб на екрані було видно, що все пораховано правильно.
